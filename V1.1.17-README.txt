MUDANÇAS CRÍTICAS
=============================================================================

MOTIVAÇÃO:
Upgrades percentuais (+5%, +10%, +15%) não funcionam com int.
Exemplo com int: 4 * 1.05 = 4.2 → 4 (perde 0.2!)
Exemplo com float: 4.0 * 1.05 = 4.2 ✓ (mantém precisão)

Sistema de upgrades futuros REQUER float para funcionar corretamente.

DECISÕES DE DESIGN
=============================================================================

1. DISPLAY ARREDONDADO (health_label):
   - Internamente: 98.7 HP (float)
   - UI mostra: "98" (int)
   - Método: int() - trunca (não arredonda para cima)
   - Razão: Mais comum em games (98.7 ≠ 99 ainda)

2. VALORES MANTIDOS:
   - 4 damage → 4.0 damage (mesmo valor)
   - Apenas tipo mudou
   - Balanceamento atual preservado

3. PREPARAÇÃO PARA UPGRADES:
   - Sistema pronto para percentuais
   - Exemplo: 4.0 * 1.15 = 4.6 damage ✓
   - Sem float: 4 * 1.15 = 4.6 → 4 ✗
