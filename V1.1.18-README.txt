=============================================================================
DECISÕES DE DESIGN
=============================================================================

1. GRUPO PROGRESSION NO TOPO:
   - Ordem no código = ordem no Inspector
   - Fácil acesso para testes
   - Mudança rápida de levels

2. ENABLED REMOVIDO:
   - current_level > 0 = mesmo efeito
   - Permite progressão (1, 2, 3, 4, 5)
   - Consistente com PowerUpData futuro

3. ÍCONES NULL OK:
   - Código defensivo (aceita null)
   - Adicionar ícones depois sem quebrar
   - Placeholder opcional no futuro

4. MÉTODOS DE CONTROLE:
   - enable_attack(): 0 → 1 (unlock)
   - upgrade_attack(): level → level+1 (progressão)
   - disable_attack(): level → 0 (lock/reset)
