=============================================================================
GUIA DE VISUALIZAÇÃO - COMO VER CADA STAT NO JOGO
=============================================================================

Este guia mostra como VISUALIZAR cada stat modificado por powerups durante
o gameplay, já que alguns não aparecem diretamente na UI.

=============================================================================
1. MAX HEALTH - ❤️ VISÍVEL NA UI
=============================================================================

ONDE VER:
- HealthBar (barra verde no topo)
- HealthLabel (número branco acima da barra)

COMO TESTAR:
1. Observe HealthLabel inicial: "1000 / 1000"
2. Pressione [1] (Vitality)
3. HealthLabel deve mudar para "1020 / 1020"
4. Pressione [5] (Warrior)
5. HealthLabel deve mudar para "1035 / 1035"
6. Pressione [R] (Reset)
7. HealthLabel deve VOLTAR para "1000 / 1000"  ← CORREÇÃO APLICADA!

VERSÃO ANTIGA (BUGADA):
- Reset não atualizava UI
- HealthLabel ficava "1035 / 1000" (errado!)

VERSÃO NOVA (CORRIGIDA):
- Reset CAP o HP atual se estiver acima do máximo
- HealthLabel vai para "1000 / 1000" (correto!)

=============================================================================
2. MOVE SPEED - 🏃 VISÍVEL NA PRÁTICA
=============================================================================

ONDE VER:
- Movimento do player (velocidade de deslocamento)

COMO TESTAR:
1. Mova o player e observe velocidade base
2. Pressione [2] (Swift Feet - +10% speed)
3. Mova o player - deve estar VISIVELMENTE mais rápido
4. Pressione [2] novamente (Lv2 - +20% total)
5. Ainda mais rápido
6. Pressione [R] (Reset)
7. Velocidade volta ao normal

CONSOLE MOSTRA:
🏃 Move Speed: 90.0 → 99.0 (Lv1)
🏃 Move Speed: 99.0 → 108.0 (Lv2)
🏃 Move Speed: 108.0 → 90.0 (Reset)

=============================================================================
3. DAMAGE - 💥 VISÍVEL AO ATACAR INIMIGOS
=============================================================================

ONDE VER:
- Dano causado nos inimigos (número de hits para matar)

COMO TESTAR SEM POWERUP:
1. Ataque um Red Gator (30 HP)
2. Conte quantos hits de Fire Power (4 dmg) precisa
3. Resultado: 8 hits (30 / 4 = 7.5)

COMO TESTAR COM POWERUP:
1. Pressione [3] (Raw Power Lv1 - +10% damage)
2. Fire Power agora causa: 4 × 1.10 = 4.4 dmg
3. Red Gator morre em 7 hits (30 / 4.4 = 6.8)
4. Pressione [3] mais vezes (Lv2 = +20%, Lv3 = +30%)
5. Inimigos morrem MAIS RÁPIDO a cada level
6. Pressione [R] (Reset)
7. Volta a precisar de 8 hits

CONSOLE MOSTRA:
💥 Damage Multiplier: ×1.00 → ×1.10 (Lv1)
💥 Damage Multiplier: ×1.10 → ×1.20 (Lv2)
💥 Damage Multiplier: ×1.20 → ×1.00 (Reset)

DICA: Foque em UM inimigo e conte os hits!

=============================================================================
4. ARMOR - 🛡️ VISÍVEL AO RECEBER DANO
=============================================================================

ONDE VER:
- Dano recebido de inimigos (quanto HP você perde)

COMO TESTAR SEM POWERUP:
1. Deixe um Red Gator te tocar (3 dmg/tick)
2. Observe HP caindo de 3 em 3
3. Exemplo: 1000 → 997 → 994 → 991

COMO TESTAR COM POWERUP:
1. Pressione [4] (Iron Skin Lv1 - 10 armor = 9% redução)
2. Red Gator agora causa: 3 × 0.91 = 2.73 dmg
3. HP cai MENOS: 1000 → 997.3 → 994.5
4. Pressione [4] novamente (Lv2 - 25 armor = 20% redução)
5. Dano: 3 × 0.80 = 2.4 dmg
6. HP cai AINDA MENOS
7. Pressione [R] (Reset)
8. Volta a receber 3 dmg

CONSOLE MOSTRA:
🛡️  Armor: 0.0 (0% damage reduction)
🛡️  Armor: 10.0 (9% damage reduction)
🛡️  Armor: 25.0 (20% damage reduction)
🛡️  Armor: 0.0 (0% damage reduction) ← Reset

DICA: Observe HealthLabel enquanto é atacado!

TABELA DE REDUÇÃO:
Lv1: 10 armor = 9% redução   → 3.0 dmg vira 2.73 dmg
Lv2: 25 armor = 20% redução  → 3.0 dmg vira 2.40 dmg
Lv3: 45 armor = 31% redução  → 3.0 dmg vira 2.07 dmg
Lv4: 75 armor = 43% redução  → 3.0 dmg vira 1.71 dmg

=============================================================================
SOBRE O RESET DO PAUSE MENU
=============================================================================

PERGUNTA: "O RESET do pause menu zera os powerups?"

RESPOSTA: SIM, automaticamente!

COMO FUNCIONA:
1. Pause menu chama get_tree().reload_current_scene()
2. Isso RECARREGA toda a cena do zero
3. PowerUpController inicializa novamente
4. Resources são duplicados com current_level = 0
5. TUDO volta ao estado inicial

TESTE:
1. Aplique vários powerups ([1][2][3][4][5])
2. Pause (ESC)
3. RESET (botão de reset)
4. Jogo reinicia
5. Todos stats voltam ao normal automaticamente

NÃO PRECISA FAZER NADA!
O reset de cena JÁ limpa tudo automaticamente.

=============================================================================
