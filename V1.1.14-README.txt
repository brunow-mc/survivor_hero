ARQUIVO 2: scripts/attack_controller.gd
───────────────────────────────────────────────────────────────────────────

MODIFICADO (_spawn_attack):
Sistema genérico com duas modalidades:

1. Se projectile_stagger_delay = 0.0:
   - Disparo SIMULTÂNEO (comportamento atual)
   - Todos projéteis spawnados ao mesmo tempo
   - AudioManager limita sobreposição via MIN_INTERVAL
   
2. Se projectile_stagger_delay > 0.0:
   - Disparo SEQUENCIAL (metralhadora)
   - Cada projétil spawna após delay
   - Cada projétil toca seu próprio áudio
   - await entre cada spawn

=============================================================================
COMO FUNCIONA - POWER_02_RING
=============================================================================

TIMELINE DE DISPARO (exemplo):
```
Configuração:
├─ Attack Delay: 0.143s
├─ Projectile Count: 3
└─ Projectile Stagger Delay: 0.15s

Execução:
0.000s: _spawn_attack() chamado
0.143s: Attack Delay cumprido
        ├─ Projétil 1 spawna
        └─ Áudio 1 toca
0.293s: (+0.15s) Projétil 2 spawna + Áudio 2 toca
0.443s: (+0.15s) Projétil 3 spawna + Áudio 3 toca
```

COMPORTAMENTO TELEGUIADO:
Cada projétil busca inimigo mais próximo NO MOMENTO DO SEU SPAWN:
- Projétil 1: busca inimigo A (mais próximo em 0.143s)
- Projétil 2: busca inimigo B (mais próximo em 0.293s)
- Projétil 3: busca inimigo C (mais próximo em 0.443s)

Efeito visual: Metralhadora atacando alvos diferentes!
