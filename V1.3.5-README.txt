REGRA PARA EDITAR LEVELS DE QUALQUER POWERUP:
----------------------------------------------

Para mudar número de levels de um powerup no Inspector:

1. Abrir o arquivo .tres do powerup
2. Editar DOIS campos:
   • max_level = [número desejado]
   • Array correspondente = [tamanho igual a max_level]
3. Salvar e testar no jogo

EXEMPLO: Aumentar Iron Skin para 6 levels:
   max_level = 6
   armor_flat_per_level = [15.0, 25.0, 45.0, 75.0, 100.0, 150.0]


IMPORTANTE - SALVAR EXPLICITAMENTE:
------------------------------------

• Se editar max_level no Inspector mas ele não aparecer no .tres,
  o Godot pode estar usando cache antigo
  
• SOLUÇÃO: Adicionar a linha manualmente no .tres:
  max_level = [valor]
  
• Isso garante que o arquivo tem o valor explícito e força reload
