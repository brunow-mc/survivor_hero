=============================================================================
❌ POSSÍVEIS PROBLEMAS E SOLUÇÕES
=============================================================================

PROBLEMA 1: "PowerUp ID 6 NÃO ENCONTRADO!"
────────────────────────────────────────────────
CAUSA: power_up_magnet.tres não tem powerup_id = 6

SOLUÇÃO:
1. Abra data/powerup_data/power_up_magnet.tres no editor de texto
2. Verifique se tem esta linha:
   powerup_id = 6
3. Se não tem, adicione após "script = ..."

PROBLEMA 2: "Magnet não está no array"
────────────────────────────────────────────────
CAUSA: PowerUpController.tscn não referencia power_up_magnet.tres

SOLUÇÃO:
1. Abra entities/power_up_controller.tscn
2. Procure a linha:
   powerups = Array[ExtResource(...)][...]
3. Verifique se tem ExtResource("8_wim2b") no final
4. Se não tem, adicione power_up_magnet.tres ao array

PROBLEMA 3: "Array size: 0" ou valores vazios
────────────────────────────────────────────────
CAUSA: magnet_range_flat_per_level está vazio

SOLUÇÃO:
1. Abra power_up_magnet.tres
2. Verifique linha:
   magnet_range_flat_per_level = Array[float]([25.0, 60.0, 105.0, 160.0])
3. Se está vazio, substitua pelo valor acima

PROBLEMA 4: "apply_powerup(6) retornou FALSE"
────────────────────────────────────────────────
CAUSA: Já está no max level OU powerup_id errado

SOLUÇÃO:
1. Se Level = 4/4: Já está no máximo!
2. Pressione [R] para resetar
3. Tente [6] novamente

PROBLEMA 5: Bonus = 0 mesmo com Level > 0
────────────────────────────────────────────────
CAUSA: Arrays não foram duplicados corretamente

SOLUÇÃO:
1. Verifique se _duplicate_powerup_resources() está sendo chamado
2. Verifique console no início do jogo:
   "🔄 PowerUpController: Resources duplicated for runtime"
