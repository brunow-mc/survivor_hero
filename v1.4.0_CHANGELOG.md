# Survivor Hero v1.4.0 - FASE 3: Pool Dinâmico

## 🎯 MUDANÇAS PRINCIPAIS

### 1. Resources - Campos de UI por Level

**AttackUpgradeData.gd:**
- Adicionado `display_name_per_level: Array[String]`
- Adicionado `description_per_level: Array[String]`
- Métodos `get_display_name_for_level(level)` e `get_description_for_level(level)`

**PowerUpData.gd:**
- Mesmos campos e métodos

### 2. Resources Preenchidos

- `attack_01_fire_upgrades.tres` - 8 levels com nomes e descrições
- `attack_02_ring_upgrades.tres` - 8 levels
- `power_up_swift_feet.tres` - 5 levels
- `power_up_vitality.tres` - 5 levels

**Quebra de linha:** Use `\n` no Inspector para múltiplas linhas na descrição.

### 3. LevelUpManager - Pool Dinâmico

**generate_upgrade_options() reescrito:**
- Consulta `AttackController.attack_upgrades`
- Consulta `PowerUpController.powerups`
- Filtra por `max_level` (não oferece upgrades maxados)
- Embaralha pool e retorna até 3 opções
- Cada opção vem com `display_name` e `description` dos Resources

### 4. LevelUpUI - Leitura Dinâmica

**level_up_ui.gd modificado:**
- `_populate_options()` ativado
- Lê `option.display_name` e `option.description` direto
- Removido código hardcoded

## 🎮 COMO FUNCIONA

```
Player upa → LevelUpManager consulta controllers
→ Filtra upgrades disponíveis
→ Sorteia 3 do pool
→ UI renderiza com dados dos Resources
→ Player escolhe → upgrade aplicado
```
