## 📝 PASSO A PASSO NO GODOT EDITOR

### PASSO 1: Abrir o projeto no Godot
1. Abrir Godot
2. Abrir o projeto "Survivor Hero"
3. Aguardar carregamento completo

---

### PASSO 2: Abrir o arquivo do Player (Major Heat)
1. No FileSystem (painel esquerdo), navegar até:
   ```
   res://entities/players/major_heat.tscn
   ```
2. Dar duplo clique para abrir a cena

---

### PASSO 3: Selecionar o AttackController
1. Na árvore de nodes (Scene, painel esquerdo superior)
2. Expandir o node "MajorHeat" (node raiz)
3. Clicar no node **"AttackController"**
4. O Inspector (painel direito) mostrará as propriedades

---

### PASSO 4: Adicionar Gear Upgrades ao Array

**No Inspector, procurar a propriedade "Attack Upgrades":**

1. Você verá: **Attack Upgrades: Array[AttackUpgradeData] (size 1)**
2. Clicar no **número "1"** para expandir o array
3. Você verá **[0]: [Attack01FireUpgrades]** (Fire já está configurado)

**Adicionar Gear:**

4. No topo do array, onde diz "size 1", clicar e mudar para **size 3**
   - Isso adicionará 2 slots vazios: [1] e [2]

5. Clicar no slot **[1]** (segundo slot)
   - Uma lista suspensa aparecerá
   - Procurar por **"Attack02RingUpgrades"** ou navegar até:
     ```
     res://data/attack_upgrade_data/attack_02_ring_upgrades.tres
     ```
   - Selecionar o arquivo

6. Clicar no slot **[2]** (terceiro slot)
   - Procurar por **"Attack05GearUpgrades"** ou navegar até:
     ```
     res://data/attack_upgrade_data/attack_05_gear_upgrades.tres
     ```
   - Selecionar o arquivo

**Resultado esperado:**
```
Attack Upgrades: Array[AttackUpgradeData] (size 3)
  [0]: [Attack01FireUpgrades]
  [1]: [Attack02RingUpgrades]
  [2]: [Attack05GearUpgrades]
```

---

### PASSO 5: Salvar a cena
1. **Ctrl+S** ou **File > Save Scene**
2. Confirmar salvamento

---

### PASSO 6: Verificar configuração dos .tres (OPCIONAL)

**Para Gear (attack_05_gear_upgrades.tres):**

1. No FileSystem, navegar até:
   ```
   res://data/attack_upgrade_data/attack_05_gear_upgrades.tres
   ```
2. Clicar no arquivo
3. No Inspector, verificar se as propriedades estão corretas:
   - **Attack Id:** 5
   - **Attack Name:** "Gear"
   - **Orbit Radius Per Level:** [0.0, 10.0, 15.0, 20.0, 30.0]
   - **Orbit Speed Bonus Per Level:** [0.0, 0.1, 0.1, 0.15, 0.15]

**Para Ring (attack_02_ring_upgrades.tres):**

1. Verificar:
   - **Attack Id:** 2
   - **Attack Name:** "Ring"
   - **Projectile Stagger Delay Per Level:** [0.0, -0.02, -0.02, -0.03, -0.05]

Se algum valor estiver errado, você pode ajustar manualmente no Inspector.

## ⚠️ TROUBLESHOOTING

### Problema: "Upgrade não encontrado" ao apertar [I]

**Solução:**
- Verificar se attack_05_gear_upgrades.tres foi adicionado ao array de upgrades no AttackController
- Verificar se o Attack Id no .tres é **5** (correspondente ao Gear)

---

### Problema: Gear não muda de comportamento ao fazer upgrade

**Solução:**
- Verificar se os arrays estão preenchidos corretamente no .tres
- Verificar no console se aparecem mensagens de upgrade (⬆️ Attack 'Gear' upgraded to level X)
- Usar [X] para listar levels e confirmar que o level está aumentando

---

### Problema: Valores errados (ex: Gear fica muito longe ou muito rápido)

**Solução:**
- Abrir attack_05_gear_upgrades.tres no Inspector
- Ajustar manualmente os valores dos arrays:
  - orbit_radius_per_level
  - orbit_speed_bonus_per_level
  - attack_scale_bonus_per_level
  - etc.
