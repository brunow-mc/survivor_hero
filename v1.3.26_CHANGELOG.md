# v1.3.26 - UNIFICAÇÃO ATTACK/POWERUP

## MUDANÇAS:

### AttackController:
- ✅ Adicionado: `apply_upgrade(id)` - método unificado
- ⚠️ Deprecated: `enable_attack(id)` e `upgrade_attack(id)` (ainda funcionam)

### PowerUpController:
- ✅ Renomeado: `apply_powerup(id)` → `apply_upgrade(id)`
- ⚠️ Deprecated: `apply_powerup(id)` (ainda funciona)

### LevelUpManager:
- ✅ Unificado: Um único método `_apply_upgrade()` para ambos
- ❌ Removido: `_apply_attack_upgrade()` e `_apply_powerup_upgrade()`

## CÓDIGO ANTES vs DEPOIS:

**ANTES:**
```gdscript
if type == "attack":
    if level == 0:
        controller.enable_attack(id)
    else:
        controller.upgrade_attack(id)
else:
    controller.apply_powerup(id)
```

**DEPOIS:**
```gdscript
controller.apply_upgrade(id)  # Funciona para Attack E PowerUp!
```

## COMPATIBILIDADE:

Scripts de teste continuam funcionando normalmente:
- `enable_attack(id)` → chama `apply_upgrade(id)` internamente
- `upgrade_attack(id)` → chama `apply_upgrade(id)` internamente
- `apply_powerup(id)` → chama `apply_upgrade(id)` internamente

## BENEFÍCIOS:

- ✅ Código 60% mais simples
- ✅ Lógica consistente Attack = PowerUp
- ✅ Base sólida para FASE 2 (UI)
- ✅ Fácil adicionar novos tipos no futuro
