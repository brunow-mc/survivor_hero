# SURVIVOR HERO - v1.3.30 CHANGELOG

## 🐛 CORREÇÃO: ESC no Menu de Level Up

### ❌ **PROBLEMA IDENTIFICADO:**

Ao pressionar ESC durante o menu de Level Up:
- ✗ Jogo despausava incorretamente
- ✗ Menu permanecia visível sobre o jogo rodando
- ✗ Jogador podia "escapar" sem escolher bônus

### 🔍 **CAUSA RAIZ:**

O problema tinha **2 camadas**:

#### **1. Conflito de Estados:**
```
LevelUpManager._on_level_up():
  → set_state(UPGRADE)
  → paused = true
  → emite upgrade_options_ready

level_up_ui._show_menu():
  → pause_game() NOVAMENTE! ← PROBLEMA
  → Muda estado de UPGRADE → PAUSED
  → previous_state = UPGRADE
```

**Resultado:** Estado ficava PAUSED em vez de UPGRADE!

#### **2. ESC não bloqueado:**
```
InputManager detecta ESC:
  → Estado atual: PAUSED
  → Chama resume_game()
  → Volta para previous_state (UPGRADE)
  → Despausa o jogo ← PROBLEMA!
```

**Resultado:** Jogo despausava mesmo em UPGRADE!

## ✅ **SOLUÇÃO IMPLEMENTADA:**

### **scripts/level_up_ui.gd**

#### **1. Removido pause_game() redundante:**

**ANTES (v1.3.29):**
```gdscript
func _show_menu() -> void:
	visible = true
	GameStateGlobal.pause_game()  # ← REDUNDANTE!
	option1.grab_focus()
```

**DEPOIS (v1.3.30):**
```gdscript
func _show_menu() -> void:
	"""Exibe o menu (jogo já está pausado pelo LevelUpManager)"""
	visible = true
	option1.grab_focus()
```

**Por quê:** LevelUpManager já pausou o jogo antes de emitir o signal!

---

#### **2. Removido resume_game() redundante:**

**ANTES (v1.3.29):**
```gdscript
func _hide_menu() -> void:
	visible = false
	GameStateGlobal.resume_game()  # ← REDUNDANTE!
```

**DEPOIS (v1.3.30):**
```gdscript
func _hide_menu() -> void:
	"""Esconde o menu (LevelUpManager vai despausar)"""
	visible = false
```

**Por quê:** LevelUpManager controla o ciclo completo de pause/resume!

---

#### **3. NOVO: Bloqueio ativo de ESC:**

**ADICIONADO:**
```gdscript
func _input(event: InputEvent) -> void:
	"""Bloqueia ESC/Pause quando menu está visível"""
	if not visible:
		return
	
	# Se menu está visível, consumir input de pause (ESC)
	if event.is_action_pressed("pause"):
		get_viewport().set_input_as_handled()  # Consome o input
```

**Como funciona:**
- Menu visível → ESC é **consumido** antes de chegar ao InputManager
- Menu invisível → ESC passa normalmente (permite pause normal)

## 🎯 **FLUXO CORRIGIDO:**

### **Level Up acontece:**
```
1. LevelUpManager._on_level_up()
   ├─ set_state(UPGRADE)
   ├─ paused = true
   └─ emite upgrade_options_ready

2. level_up_ui._on_upgrade_options_ready()
   ├─ _populate_options()
   └─ _show_menu()
        ├─ visible = true
        └─ grab_focus()

Estado: UPGRADE ✅
Pausado: true ✅
```

### **Jogador aperta ESC:**
```
1. level_up_ui._input()
   └─ Detecta "pause"
   └─ set_input_as_handled() ← CONSOME!

2. InputManager._unhandled_input()
   └─ NÃO recebe o evento! ✅

Estado: UPGRADE ✅ (não muda)
Pausado: true ✅ (não muda)
```

### **Jogador escolhe bônus:**
```
1. level_up_ui._on_option_pressed()
   ├─ emite option_selected
   └─ _hide_menu()
        └─ visible = false

2. LevelUpManager.apply_upgrade()
   ├─ Aplica upgrade
   ├─ set_state(COMBAT)
   └─ paused = false

Estado: COMBAT ✅
Pausado: false ✅
```

## 🎓 **LIÇÕES APRENDIDAS:**

### **Princípio de Responsabilidade Única:**
- **LevelUpManager:** Controla estado e pause/resume
- **level_up_ui:** Apenas exibe/esconde interface
- **Não duplicar** responsabilidades!

### **Consumo de Input:**
- `set_input_as_handled()` previne propagação
- Permite bloqueio seletivo (só quando menu visível)
- Mais robusto que verificações de estado

### **Debugging de Estados:**
- Estados duplicados/conflitantes são difíceis de debugar
- Sempre verificar **quem controla o quê**
- Console logs ajudam a rastrear mudanças de estado

## 📝 **NOTAS TÉCNICAS:**

**set_input_as_handled():**
- Marca input como "consumido"
- Previne que chegue a `_unhandled_input()`
- Funciona porque level_up_ui usa `_input()` (processado antes)

**process_mode = ALWAYS:**
- level_up_ui continua processando mesmo pausado
- Permite capturar ESC enquanto jogo está pausado
- Essencial para bloqueio funcionar

**Ordem de processamento:**
```
1. _input() ← level_up_ui captura aqui
2. _gui_input() 
3. _unhandled_input() ← InputManager só recebe se não foi handled
```
