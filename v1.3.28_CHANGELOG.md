### ⚙️ FUNCIONAMENTO

#### Fluxo Completo:
1. Player sobe de level → XPManager emite `level_up`
2. LevelUpManager:
   - Pausa o jogo
   - Gera 3 opções (FIXAS na FASE 2)
   - Emite `upgrade_options_ready`
3. UI recebe signal:
   - Preenche 3 botões com dados
   - Exibe menu
   - Dá focus no primeiro botão
4. Player escolhe via mouse/teclado
5. UI emite `option_selected`
6. LevelUpManager aplica upgrade
7. Menu some e jogo continua

#### Controles:
- **Mouse:** Clique em qualquer parte do botão
- **Teclado:**
  - ↑↓ - Navega entre opções
  - Enter - Confirma escolha
