=============================================================================
PASSO 1: ADICIONAR POWERUPCONTROLLER AO MAJOR_HEAT
=============================================================================

NO GODOT:

1. Abra a cena: entities/players/major_heat.tscn

2. Na árvore de cena (Scene tree), clique em "Major_Heat" (raiz)

3. Clique no ícone "+" ou clique direito → "Instantiate Child Scene"

4. Navegue até: entities/power_up_controller.tscn

5. Selecione e clique "Open"

6. A cena PowerUpController deve aparecer como FILHO de Major_Heat:
   
   Major_Heat (CharacterBody2D)
   ├─ AttackController
   ├─ PowerUpController ← NOVO
   └─ (outros nodes)

7. Salve a cena (Ctrl+S)

VERIFICAR:
- PowerUpController está FILHO DIRETO de Major_Heat
- PowerUpController tem o ícone de cena instanciada (não node solto)

=============================================================================
PASSO 2: CONFIGURAR ARRAY DE POWERUPS
=============================================================================

NO GODOT (com major_heat.tscn aberta):

1. Selecione "PowerUpController" na árvore de cena

2. No Inspector (lado direito), procure "Powerups"

3. Clique em "Powerups" para expandir

4. Mude "Array[PowerUpData] (size 0)" para "size 5"

5. Preencha os slots:
   [0] = powerup_vitality.tres
   [1] = powerup_swift_feet.tres
   [2] = powerup_raw_power.tres
   [3] = powerup_iron_skin.tres
   [4] = powerup_warrior.tres

COMO PREENCHER CADA SLOT:
- Clique no slot [0]
- Clique no ícone de pasta (Browse)
- Navegue até: data/powerup_data/powerup_vitality.tres
- Selecione e clique "Open"
- Repita para os outros 4 slots

6. Salve a cena (Ctrl+S)

VERIFICAR NO INSPECTOR:
Powerups ▼
├─ [0]: powerup_vitality.tres
├─ [1]: powerup_swift_feet.tres
├─ [2]: powerup_raw_power.tres
├─ [3]: powerup_iron_skin.tres
└─ [4]: powerup_warrior.tres

=============================================================================
PASSO 3 (OPCIONAL): ADICIONAR TESTPOWERUPS PARA DEBUG

TROUBLESHOOTING
=============================================================================

ERRO: "Could not resolve class 'PlayerBase'" ou "BasePower"
SOLUÇÃO: Feche e reabra o projeto no Godot. Esses erros devem desaparecer 
         após o Godot recarregar os scripts.

ERRO: "Identifier 'PlayerStatsGlobal' not declared"
SOLUÇÃO: PlayerStatsGlobal já está configurado no project.godot. Feche e 
         reabra o projeto.

ERRO: "PowerUpController: Parent is not PlayerBase!"
SOLUÇÃO: PowerUpController não está filho direto de Major_Heat (Passo 1)

ERRO: "PowerUp ID X não encontrado"
SOLUÇÃO: Array de powerups não configurado no Inspector (Passo 2)

NENHUM PRINT APARECE:
SOLUÇÃO: PowerUpController não foi adicionado ao major_heat.tscn (Passo 1)

TECLAS NÃO FUNCIONAM:
SOLUÇÃO: TestPowerups não foi adicionado como filho de Major_Heat (Passo 3)

🔄 RESET DO PAUSE MENU
=============================================================================

PERGUNTA: "O reset do pause menu zera os powerups?"

RESPOSTA: SIM! Automaticamente.

COMO FUNCIONA:
1. Pause menu chama get_tree().reload_current_scene()
2. Toda a cena é RECARREGADA do zero
3. PowerUpController inicializa novamente
4. Resources duplicados com current_level = 0
5. TODOS os stats voltam ao base

NÃO PRECISA FAZER NADA MANUALMENTE!
O reset de cena JÁ limpa tudo automaticamente.

COMO CONFIRMAR:
- HealthLabel volta ao valor base (ex: 1000)
- Move Speed volta ao normal
- Damage volta ao base (conta hits novamente)
- Armor zerado (dano recebido volta ao normal)
