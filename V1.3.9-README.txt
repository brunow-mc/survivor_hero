## 🚀 NOVAS VARIÁVEIS v1.3.9

### 1. PROJECTILE_STAGGER_DELAY (Ritmo de Disparos)

**Tipo:** float  
**Método:** ADITIVO (`base + bonus`)  
**Permite valores negativos:** ✅ SIM (acelera disparos)

**Uso principal:** Power_02_Ring (disparo sequencial)

**Por que é importante:**
- Controla intervalo entre disparos sequenciais
- Ring atualmente usa 0.22s entre projéteis
- Valores negativos = rajada mais rápida
- Valores positivos = disparos mais espaçados (raramente útil)

**Exemplo (Ring - base 0.22s):**
```
Level 1: 0.22 + 0.00 = 0.22s (base - disparo "metralhadora")
Level 2: 0.22 - 0.02 = 0.20s (mais rápido)
Level 3: 0.22 - 0.02 - 0.02 = 0.18s (ainda mais rápido)
Level 4: 0.22 - 0.02 - 0.02 - 0.03 = 0.15s (rajada rápida)
Level 5: 0.22 - 0.02 - 0.02 - 0.03 - 0.05 = 0.10s (quase simultâneo)
```

**Comportamento com 0.0s:**
- Se stagger_delay chegar a 0.0 → disparos simultâneos
- Útil para transformar disparo sequencial em "shotgun"

---

### 2. ORBIT_RADIUS (Alcance Orbital)

**Tipo:** float  
**Método:** ADITIVO (`base + bonus`)  
**Permite valores negativos:** ✅ SIM (aproxima do player)

**Uso principal:** Power_05_Gear (órbita ao redor do player)

**Por que é importante:**
- Controla distância do Gear ao player
- Gear base = 50.0 pixels de raio
- Raio maior = proteção mais ampla, mas cobertura menos densa
- Raio menor = proteção mais próxima, cobertura mais densa

**Exemplo (Gear - base 50.0):**
```
Level 1: 50 + 0 = 50px (base - proteção próxima)
Level 2: 50 + 10 = 60px (alcance médio)
Level 3: 50 + 10 + 15 = 75px (alcance grande)
Level 4: 50 + 10 + 15 + 20 = 95px (alcance muito grande)
Level 5: 50 + 10 + 15 + 20 + 30 = 125px (alcance máximo - 2.5x base)
```

**Trade-off interessante:**
- Órbita pequena + muitos gears = "escudo denso"
- Órbita grande + poucos gears = "sentinelas espaçadas"

---

### 3. ORBIT_SPEED (Velocidade Orbital)

**Tipo:** float  
**Método:** MULTIPLICATIVO (`base * (1.0 + bonus)`)  
**Permite valores negativos:** ⚠️ Sim, mas cuidado (inverte rotação se < -1.0)

**Uso principal:** Power_05_Gear (velocidade de rotação)

**Por que é importante:**
- Controla velocidade de rotação do Gear
- Gear base = 3.0 rad/s
- Velocidade maior = cobertura mais rápida, dificulta acerto de inimigos
- Velocidade menor = cobertura mais lenta, facilita timing

**Exemplo (Gear - base 3.0):**
```
Level 1: 3.0 × (1.0 + 0.00) = 3.0 rad/s (base - 1 rotação ~2s)
Level 2: 3.0 × (1.0 + 0.10) = 3.3 rad/s (10% mais rápido)
Level 3: 3.0 × (1.0 + 0.20) = 3.6 rad/s (20% mais rápido)
Level 4: 3.0 × (1.0 + 0.35) = 4.05 rad/s (35% mais rápido)
Level 5: 3.0 × (1.0 + 0.50) = 4.5 rad/s (50% mais rápido - 1 rotação ~1.4s)
```

**Sinergia com orbit_radius:**
- Raio grande + velocidade alta = "helicóptero de ataque"
- Raio pequeno + velocidade baixa = "escudo denso e controlado"
