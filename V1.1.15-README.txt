MODIFICADO (set_attack_data):
Adicionada chamada para _apply_attack_scale()

ADICIONADO (função nova):
```gdscript
func _apply_attack_scale() -> void:
    if not attack_data:
        return
    
    var scale_vec := Vector2(attack_data.attack_scale, attack_data.attack_scale)
    
    for child in get_children():
        if child is CollisionShape2D or child is AnimatedSprite2D:
            child.scale = scale_vec
```

ARQUIVO 3: scripts/attack_controller.gd (CORREÇÃO CRÍTICA)
───────────────────────────────────────────────────────────────────────────

MODIFICADO (_duplicate_attack_resources):
Duplicação MANUAL de HitData para evitar compartilhamento

```gdscript
func _duplicate_attack_resources() -> void:
    var duplicated: Array[AttackData] = []
    
    for attack in attacks:
        if attack:
            var dup_attack = attack.duplicate(true)
            
            # CRÍTICO: Duplicar HitData manualmente
            if dup_attack.hit_data:
                dup_attack.hit_data = dup_attack.hit_data.duplicate(true)
            
            duplicated.append(dup_attack)
        else:
            duplicated.append(null)
    
    attacks = duplicated
```

COMO FUNCIONA
=============================================================================

AUTOMÁTICO PARA TODOS OS POWERS:

Quando attack_data é configurado no power:
1. set_attack_data() é chamado (como sempre foi)
2. _apply_attack_scale() é chamado automaticamente
3. Percorre todos os children do power
4. Se é CollisionShape2D ou AnimatedSprite2D:
   └─ Aplica scale = Vector2(attack_scale, attack_scale)

EXEMPLOS:
```
attack_scale = 1.0 (padrão):
├─ CollisionShape2D: tamanho original
└─ AnimatedSprite2D: tamanho original

attack_scale = 0.65:
├─ CollisionShape2D: 65% do tamanho
└─ AnimatedSprite2D: 65% do tamanho

attack_scale = 1.35:
├─ CollisionShape2D: 135% do tamanho
└─ AnimatedSprite2D: 135% do tamanho
```
