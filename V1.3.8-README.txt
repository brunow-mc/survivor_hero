## 🚀 NOVAS VARIÁVEIS DE UPGRADE

### 1. PROJECTILE_ANGLE_SPREAD (Dispersão de Projéteis)

**Tipo:** float  
**Método:** ADITIVO (`base + bonus`)  
**Permite valores negativos:** ✅ SIM

**Por que é importante:**
- Com 1 projétil: ângulo não afeta (irrelevante)
- Com 2+ projéteis: controle fino da dispersão do leque
- Valores negativos fecham o leque, positivos abrem

**Exemplo (Fire - base 15.0°):**
```
Level 1: 1 proj  → 15 + 0.0 = 15° (irrelevante)
Level 2: 2 proj  → 15 + 5.0 = 20° (leque mais aberto)
Level 3: 3 proj  → 15 + 5.0 - 5.0 = 15° (volta ao normal)
Level 4: 4 proj  → 15 + 5.0 - 5.0 + 0.0 = 15°
Level 5: 5 proj  → 15 + 5.0 - 5.0 + 0.0 - 3.0 = 12° (mais fechado)
```

---

### 2. LIFE_TIME (Tempo de Vida)

**Tipo:** float  
**Método:** ADITIVO (`base + bonus`)  
**Permite valores negativos:** ⚠️ Tecnicamente sim, mas não recomendado

**Por que é importante:**
- Aumenta alcance efetivo de projéteis que viajam
- Crítico para Fire, Ring
- Menos útil para Electricity, Gear (attach_to_player)

**Exemplo (Fire - base 1.7s):**
```
Level 1: 1.7 + 0.0 = 1.7s (base)
Level 2: 1.7 + 0.3 = 2.0s
Level 3: 1.7 + 0.3 + 0.3 = 2.3s
Level 4: 1.7 + 0.3 + 0.3 + 0.4 = 2.7s
Level 5: 1.7 + 0.3 + 0.3 + 0.4 + 0.5 = 3.2s
```

---

### 3. ATTACK_SCALE (Escala Visual/Colisão)

**Tipo:** float  
**Método:** MULTIPLICATIVO (`base * (1.0 + bonus)`)  
**Permite valores negativos:** ⚠️ Sim, mas cuidado (valores < -1.0 invertem escala)

**Por que é importante:**
- Afeta visual E mecânica (área de colisão)
- Todos os 5 poderes já suportam scale corretamente
- Power_04_bo tem escala dinâmica (cresce/diminui com movimento)

**Exemplo (Fire - base 1.0):**
```
Level 1: 1.0 × (1.0 + 0.0) = 1.0 (100% - base)
Level 2: 1.0 × (1.0 + 0.05) = 1.05 (105%)
Level 3: 1.0 × (1.0 + 0.10) = 1.10 (110%)
Level 4: 1.0 × (1.0 + 0.20) = 1.20 (120%)
Level 5: 1.0 × (1.0 + 0.35) = 1.35 (135%)
```
